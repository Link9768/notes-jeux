Installer le favori Matchmaking LBC

Matchmaking LBC

PC : glisse le lien dans ta barre de favoris. Android (Chrome) : crée un favori de n'importe quelle page, remplace son adresse par le code ci-dessus et nomme-le « Matchmaking LBC » ; sur leboncoin.fr, tape « Matchmaking LBC » dans la barre d'adresse et choisis le favori.

Ensuite : clique sur Leboncoin ci-dessus, puis lance le favori sur l'onglet Leboncoin.

Installer le favori Matchmaking Okkazeo (plus de 64 jeux)

Matchmaking Okkazeo

PC : glisse le lien dans ta barre de favoris. Android (Chrome) : crée un favori de n'importe quelle page, remplace son adresse par le code ci-dessus et nomme-le « Matchmaking Okkazeo » ; sur okkazeo.com, tape « Matchmaking Okkazeo » dans la barre d'adresse et choisis le favori.

Au-delà de 64 jeux, le serveur ralentit (1 requête/s) pour ne pas être bloqué par Okkazeo ; le favori fait la recherche depuis ton navigateur. Clique sur Okkazeo (favori), puis lance le favori sur l'onglet Okkazeo.
